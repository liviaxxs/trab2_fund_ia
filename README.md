# trab2_fund_ia
Infraestrutura e modelo do problema para o TP2 de Fundamentos de IA (UFMG). Contém parsing de instâncias, função de fitness h(π) validada, operadores de vizinhança (Swap, Insertion, 2-opt), avaliação incremental em swap e testes automáticos de integridade com medição de tempo de parede.
